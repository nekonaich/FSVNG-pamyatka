# Памятка по набору в ФСВНГ

Статичный сайт-памятка: порядок набора, гос. волна, тренировки, выезд на стрельбище и законодательная база (УК, КоАП, Трудовой кодекс РО). Без сборки и зависимостей: открывается как обычный HTML.

## Структура

```
index.html        страница и весь текст (вкладки, кодексы)
assets/style.css  оформление
assets/app.js     вкладки, переключатель кодексов, поиск, кнопки «Копировать»
version.json      номер версии и список изменений для окна обновления
.nojekyll         отключает обработку Jekyll на GitHub Pages
```

## Запуск локально

Открой `index.html` в браузере. Шрифты (Oswald, Roboto) подгружаются с Google Fonts, без интернета сработают запасные.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Памятка по набору в ФСВНГ"
git branch -M main
git remote add origin https://github.com/<имя>/<репозиторий>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save**. Через минуту-две сайт будет доступен по адресу `https://<имя>.github.io/<репозиторий>/`.

## Как редактировать

- Текст вкладок «Набор в ФСВНГ», «Тренировки» и «Выезд на стрельбище» лежит в `index.html` в блоках `cat-a`, `cat-b`, `cat-c`.
- Кодексы лежат в блоках `law-uk`, `law-koap`, `law-tk`. Каждая статья это `<div class="card art">` с заголовком `<h3>`.
- Ссылки на оригиналы на форуме заданы атрибутом `data-u` у карточек кодексов.
- Скриншоты полосы препятствий встроены в страницу как base64.

## Окно обновления

При входе посетитель один раз видит окно «Сайт обновлён» со списком изменений (что добавлено, изменено, убрано). Открытая страница сама проверяет `version.json` каждые 30 секунд и при возвращении на вкладку. Если версия на сервере новее, появляется окно «Доступна новая версия сайта» с кнопкой «Обновить страницу».

Чтобы выпустить обновление:

1. В `assets/app.js` измени в объекте `SITE` поля `version`, `date`, `added`, `changed`, `removed`.
2. Сделай такие же изменения в `version.json`.
3. В `index.html` замени `?v=...` у `style.css` и `app.js` на новый номер версии, чтобы браузеры не брали старые файлы из кэша.
4. Закоммить и запушь. GitHub Pages обновляется за 1–2 минуты.
